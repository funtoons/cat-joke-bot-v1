## How it works

Run `python3 main.py`. The program writes exactly one joke — a single line of
UTF-8 text, 125 characters, no trailing newline — to `/output/entry.txt`.

The joke is a fixed string in `main.py`: no network, no randomness, no
timestamps, so every run produces byte-identical output.
